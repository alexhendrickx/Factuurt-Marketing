# App-screenshots

Deze directory bevat app-screenshots die gegenereerd zijn door `scripts/take-screenshots.ts` via Playwright. De huidige PNG's zijn placeholders met een grijze achtergrond; zij dienen als gate-borging zodat de site zonder de draaiende app kan builden. Echte app-beelden worden gegenereerd door `npm run screenshots` uit te voeren met een lokale factuurt-app en demo-seed. Zie `.claude/state/plans/m1-visuals-pipeline.md` voor details over de pipeline en hoe deze uit te voeren.
